# Ft_printf
Este projeto foi criado como parte do currículo da 42 por ganselmo

# Descrição
O ft_printf é uma reimplementação da função printf() da biblioteca padrão do C. O objetivo do projeto é recriar seu comportamento essencial, entendendo profundamente como funcionam funções variádicas e o processamento de formatos.

Ela interpreta uma string de formatação e trata diferentes tipos de conversões, imprimindo os argumentos recebidos de acordo com os especificadores definidos.

O projeto exige suporte para:

- %c → caractere

- %s → string

- %p → ponteiro (em hexadecimal)

- %d / %i → inteiro decimal

- %u → inteiro decimal sem sinal

- %x → hexadecimal minúsculo

- %X → hexadecimal maiúsculo

- %% → símbolo %

Principais conceitos envolvidos

- Uso de va_list, va_start, va_arg e va_end

- Conversão de números para diferentes bases

- Manipulação de ponteiros

- Escrita controlada com write
